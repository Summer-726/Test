# AI 经济顾问（微信小程序 · 测试版）

面向"没有独立收入的学生"的 AI 经济顾问，解决两个核心痛点：
- **无意识超支**——生活费在不知不觉中花超
- **花钱没换来相应的情绪回报**——钱花了却不一定开心

## 项目是什么

- 📄 **手动记账**：输一句话，AI 自动分类（6 类）；可改日期补记、左滑撤回
- 💰 **三分预算**：生活费按「日常 / 应急 / 存款」分（预设 3 档 + 自定义比例），日常 70%/90% 预警、跨月结转、可设存钱目标
- 💬 **带真实账本的 AI 顾问**：DeepSeek，随时问「该不该买 X」「钱花哪了」；多会话对话、记住最近 8 条上下文
- 📊 **汇报与总结**：今日 / 本月汇报（随时点，自动带上最近聊过的上下文）+ 总结页分类图表

## 技术栈

微信小程序前端（WXML / WXSS / JavaScript）+ 微信云开发·云函数（Node.js）+ DeepSeek API + 手机本地存储
