设计说明

  • ①
    字母 C 就是一枚"开口的硬币"——白带圆环 + 右侧开口，既是字母 C，也是零钱元素本尊。
  • ②
    A 叠进 C 的开口——左腿下缘压住 C 的带宽，两字真实交织，一眼读出 "CA"。
  • ③
    后景一枚淡硬币——两枚硬币叠放 = "零钱"（复数），低调不抢主标。
  • ④
    苹果蓝渐变 + 顶部微光——克制配色、无边框，高级简约。
