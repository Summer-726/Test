# 账号设置教程（阶段 0）· docs/account-setup.md

> 手把手教程，教你完成 4 步账号操作。完成后我们才能开发和测试小程序。
> 全程只需要 **手机 + 身份证 + 邮箱/手机号**，不需要任何代码。
> 界面文字以微信官方实际显示为准；各步骤耗时 10 分钟 ~ 1 天（含审核）。

## 总览

| 步骤 | 干什么 | 大概耗时 |
|---|---|---|
| 1 | 安装微信开发者工具 | 10 分钟 |
| 2 | 注册小程序账号，拿 AppID | 10 分钟 ~ 1 天（审核） |
| 3 | 开通云开发，建环境 | 10 分钟 |
| 4 | 注册 DeepSeek，拿 API key | 10 分钟 |

---

## 第 1 步：安装微信开发者工具

1. 打开官方下载页：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 选 **macOS 版**，下载 `.dmg` 安装包
3. 打开安装包，把「微信开发者工具」拖进「应用程序」
4. 打开它，用**你的微信扫码登录**（第一次会用你的微信绑定）

> 装完先不用建项目，等代码写好后再导入。

---

## 第 2 步：注册小程序账号，拿 AppID

1. 浏览器打开 **微信公众平台**：https://mp.weixin.qq.com
2. 点右上角「立即注册」→ 选 **小程序**
3. 填邮箱、设密码，去邮箱收激活邮件
4. 主体类型选 **个人**（自己用，免费注册，不需要营业执照）
5. 管理员微信扫码验证 + 填姓名、身份证号（实名认证）
6. 提交后等审核（一般几小时 ~ 1 天）
7. 通过后登录公众平台 → 左侧「设置」→「基本设置」→ 复制 **AppID**（18 位字母数字）
8. **保存好 AppID**，后面开发要用

> ⚠️ 测试版用**个人主体**注册即可。个人小程序不能做微信支付收款等商业功能，但我们的顾问产品不需要这些，完全够用。

---

## 第 3 步：开通云开发，建环境

1. 打开微信开发者工具（第 1 步装的）
2. 用注册时绑定的微信扫码登录
3. 创建项目：项目名称随意（如 `ai-advisor`），**AppID 填第 2 步拿到的**，后端服务选「微信云开发」
4. 创建后，点顶部工具栏的「云开发」按钮
5. 首次会提示开通：创建一个环境，环境名随意（如 `test`），配额选「**免费体验环境**」（测试版够用，不用花钱）
6. **记下这个环境 ID**

> 免费体验环境有资源上限，但测试阶段完全够；等以后正式发布再升级付费版（约 19.9 元/月）。

---

## 第 4 步：注册 DeepSeek 开放平台，拿 API key

1. 打开：https://platform.deepseek.com
2. 注册并登录（手机号或邮箱）
3. 进入「API Keys」页面 → 点「创建」→ 复制生成的 key
4. ⚠️ **key 只显示这一次**，务必立刻保存好（比如存到手机备忘录）
5. 说明：DeepSeek 按用量收费，测试阶段用量极小、费用几乎可忽略；首次可能需要小额充值或实名，按平台提示操作即可

> 🔐 **隐私承诺**：你的 key 只会在最后一步填进「云函数环境变量」（云端），**绝不会写进小程序前端代码**，也不会出现在 GitHub 上。

---

## 完成后

4 步都完成，保存好这三样东西，告诉开发者"账号准备好了"：

| 东西 | 形如 | 用途 |
|---|---|---|
| AppID | `wx1234567890abcdef` | 创建小程序项目 |
| 云开发环境 ID | 一串小写字母数字 | 连接云函数 |
| DeepSeek API key | `sk-xxxxxxxx` | AI 调用 |

> 不需要把这三个值发到任何聊天里；开发者会教你把它们填进**本地配置文件 / 云函数环境变量**（只存在你自己电脑和微信云端，不公开）。
