# 设计规范：苹果风 UI（微信小程序 · 测试版）

> 本文件是界面设计标准文档。目标：**干净、高级、打开就会用**——像苹果一样简单高级的美感。
> 来源：需求 §8 UI 结构 + §9 设计原则。最后更新：2026-08-10

## 1. 设计原则

- **极简克制的配色**：中性色为主 + 少量强调色
- **大留白**：宁可空，不要挤
- **清晰的文字层级**：一眼看出主次
- **圆角卡片**：内容区用卡片承载
- **细腻动效**：过渡柔和，不花哨

## 2. 色彩规范（全局统一）

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面背景 | `#f5f5f7` | 苹果风浅灰 |
| 主文字 | `#1d1d1f` | 近黑，正文 |
| 次要文字 | `#86868b` | 灰，辅助说明 |
| 强调色（主按钮/选中） | `#0a84ff` | 苹果蓝 |
| 警示色 | `#ff3b30` | 超支/预警 |
| 卡片背景 | `#ffffff` | 白色圆角卡片 |
| tabBar 未选中 | `#8e8e93` | 灰 |

## 3. 文字层级

| 层级 | 字号/字重 | 用途 |
|---|---|---|
| 页面大标题 | 44rpx / 600 | 页面顶部标题 |
| 卡片标题 | 34rpx / 600 | 卡片内主标题 |
| 卡片主数字（金额等） | 64rpx / 600 | 三罐余额等大数字 |
| 正文 | 28rpx / 400 | 一般文字 |
| 辅助说明 | 26rpx / 400 · 灰 | 次要信息、提示 |

## 4. 组件规范

| 组件 | 规范 |
|---|---|
| 卡片 card | 白色底、圆角 28rpx、内边距 32rpx、外边距 24rpx 32rpx、极轻阴影 `0 4rpx 16rpx rgba(0,0,0,0.04)` |
| 主按钮 btn-primary | 胶囊形（border-radius 999rpx）、苹果蓝底白字、居中、padding 24rpx 0 |
| 分段控件 | 预算页 [预算 \| 规划] 切换 |
| 底部 tabBar | 4 项（首页/记账/问AI/洞察），纯文字，选中苹果蓝（阶段 6 可加图标） |
| 预警提示 | 黄色/红色背景条，用于 70%/90% 超支提醒 |

## 5. 页面结构（来源：需求 §8）

- **底部 4 tab**：首页 / 记账 / 问AI / 洞察
- **首页概览**：三罐状态卡（花罐占主位，救急/存辅助）+ 今日/本月汇报按钮 + 顾问提醒卡片 + 最近 5 笔消费
  - 点"三罐状态卡" → 进入「预算」页
- **预算页**（页内分段切换 [预算 \| 规划]）：本月生活费 / 三罐比例 / 存钱目标
- **记账页**：金额数字键盘 + 描述输入（AI 自动分类）+ 支出/收入切换 + 扣款来源三选一（花/救急/存）+ 日期
- **问 AI 页**：聊天界面（保留历史），顾问基于数据说开场白
- **洞察页**：各分类"花费 + 后悔率"图表 + AI 点评（最值/最不值）+ 文字建议

## 6. 迭代方式

- 开发时先出高保真原型逐屏打磨，视觉允许迭代调整（需求 §9）
- 阶段 6 做全局视觉打磨：配色、留白、动效、圆角统一
