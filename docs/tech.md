# 技术方案：AI 经济顾问（微信小程序 · 测试版）

> 本文件是技术标准文档。需求背景见 [requirements.md](requirements.md)，执行步骤见 [development-plan.md](development-plan.md)。
> 最后更新：2026-08-10

## 1. 技术栈总览

| 层 | 技术 | 谁负责 |
|---|---|---|
| 小程序前端 | 微信小程序（WXML / WXSS / JavaScript） | 开发者（代码全由开发者完成） |
| 云端 | 微信云开发 · 云函数（Node.js） | 开发者 |
| AI | DeepSeek API（key 存云函数环境变量，不暴露前端） | 开发者接入 / 用户提供 key |
| 数据 | 手机本地存储（wx 本地存储），隐私优先 | 开发者 |
| 开发工具 | 微信开发者工具（macOS） | 用户安装 |

## 2. 为什么这么选（关键决策理由，来源：需求 §5）

- **手动记账为主**：iPhone（iOS）沙盒机制，任何 App 都无法读取微信支付数据；安卓需"读取短信/无障碍"敏感权限且不稳定。自动记账留到未来（账单文件导入）。详情见需求 §5.1
- **DeepSeek API + 提示词 + RAG，不做训练/微调**：特色来自"顾问手册提示词 + 实时账本数据 + 产品逻辑"，不来自模型本身。详情见需求 §5.2
- **隐私设计**：账目数据存手机本地；DeepSeek key 只放云函数环境变量，绝不进前端代码。详情见需求 §5.3
- **成本**：测试阶段用云开发免费体验环境；DeepSeek 按 token 计费、个人用量极小。详情见需求 §5.4

## 3. 数据设计（全部存手机本地）

### 3.1 账本条目 ledger[]
```js
{
  id: "唯一编号",
  type: "expense" | "income",         // 支出 / 收入
  amount: 12.5,                       // 金额
  desc: "和朋友看了场电影",           // 用户输入的文字
  category: "娱乐",                   // AI 分类，兜底"其他"，可手改
  jar: "flower" | "rescue" | "savings", // 扣款来源（收入时为空）
  date: "2026-08-10",                 // 日期，默认当天
  worth: null | {                     // 值得度评价（可选）
    need: "需要"|"想要"|"说不清",
    again: "会"|"不会"|"不确定"
  }
}
```

### 3.2 月度配置 monthConfig（每月一份）
```js
{
  yearMonth: "2026-08",
  totalIncome: 1500,                    // 本月总收入（生活费 + 额外收入）
  ratio: { flower: 70, rescue: 15, savings: 15 }, // 三罐比例，可调
  carry: { rescue: 0, savings: 0 }      // 上个月结转进来的救急/存余额
}
```

### 3.3 存钱目标 savingsGoal（可选，设置时询问有无存钱计划）
```js
{ name: "换手机", target: 3000, saved: 0 }
```

### 3.4 聊天历史 chatSessions[]（本地保留，多会话）
> 2026-08-11 决策：AI 对话做**多会话**。本地键名 `chatSessions`，按"会话 → 消息"两级存。单会话只保留最近 40 条（数据最小化）。
```js
[{
  id: "sess-xxx", title: "自动取首条用户消息前 12 字", createdAt: "...",
  messages: [{ role: "user"|"assistant", text: "...", time: "..." }]
}]
```

### 3.5 月度回顾存档 reports[]（每月自动生成后归档）
```js
[{ yearMonth: "2026-08", content: "AI 生成的完整报告", generatedAt: "..." }]
```

## 4. AI 集成设计

- **一个云函数 `ai`**，按参数 `mode` 分发到三种任务，减少维护成本：
  - `classify`：把描述归类到固定 6 类（餐饮/交通/购物/娱乐/学习/其他）
  - `chat`：顾问对话（携带账本数据，RAG）
  - `report`：生成今日/本月汇报、月度回顾
- 云函数内调用 DeepSeek：直接 HTTPS 请求 `https://api.deepseek.com/chat/completions`（OpenAI 兼容）
- **key 只放云函数环境变量**，前端代码里绝不出现
- **数据最小化**：只把"本次需要"的数据拼进提示词（如对话只带最近 20 笔），不外传、不落库
- 前端调用方式：`wx.cloud.callFunction({ name: "ai", data: { mode, ... } })`

## 5. 顾问手册（提示词）核心要点

- 用户是"没有独立收入的学生"，生活费来自父母/亲戚
- 语气温和但直接，帮用户分清"需要 vs 想要"
- 不做投资建议，定位"参考 + 教育"，界面有免责提示
- 引用用户真实账本数据说话，不空谈
